# 점검 규칙 — 외부 AI 계약서 초안 점검기

다른 AI(ChatGPT 등)가 작성한 「재무자문 및 자금조달 컨설팅 계약서」 초안을 붙여 넣으면 아래 세 묶음으로 점검합니다.
결과는 **⚠ 경고**(사람이 검토해야 함)와 **✕ 오류**(서명 전에 반드시 고쳐야 함)로 표시하고, 해당 문장을 그대로 보여 줍니다.
점검은 키워드 기반 **참고용**이며, 법률 판단을 대신하지 않습니다.

## A. 위험 표현 (⚠ 경고)
부정·면제 문장("~하지 아니한다", "~이 아님을", "~와 관계없이", "~여부와 별도로")은 위험 표현에서 제외합니다.
"다음 업무는 포함하지 않는다"처럼 부정 문장 바로 아래에 오는 번호 목록(1. 2. …)도 부정된 것으로 봅니다.

| 코드 | 이름 | 조건 | 왜 |
|---|---|---|---|
| R1 | 성과 연동 보수 | 한 문장에 *보수·수수료·자문료* 와 *(대출·투자·자금조달·조달) + (실행·승인·약정·유치·성사·성공·완료·확정)* 또는 *대출금·투자금·조달금액* 이 함께 있음 (어순·조사 차이 허용, 예: "자금조달에 성공한 경우") | 보수가 대출·투자 성사에 연동되면 대부업법(무등록 중개)·자본시장법(무인가 투자중개) 검토 필요 |
| R2 | 중개성 표현 | *알선 / 주선 / 중개 / 소개* 가 있음 ("소개 자료", "소개서"는 제외) | 업무가 중개로 읽힐 수 있음 |
| R4 | '성공보수·성과보수' 표현 | *성공보수 / 성과보수* 라는 말이 있음 (화면에는 처음 3문장과 "외 N곳"만 표시) | 이름만으로도 성사 연동 보수로 읽힐 수 있음 (대표 판단) |
| R3 | 성사 보장 표현 | *보장 / 확약 / 책임지고* 가 *대출·투자·조달·승인·성사·유치* 와 한 문장에 있음 (의뢰인의 "자료 정확성 보장"은 제외) | 자문사가 대출·투자 결과를 약속하는 것으로 읽힘 |

## B. 필수 조항 (✕ 없으면 오류)
| 코드 | 조항 | 찾는 표현 |
|---|---|---|
| C1 | 중개 금지(자문 한정) | *중개·알선·주선* + *아니·않* 이 한 문장에 |
| C2 | 성사 여부와 무관한 보수 지급 | *관계없이 / 무관하게 / 상관없이 / 여부와 별도로* + *성사·실행·조달·유치·성공* 이 한 문장에 |
| C3 | 업무 범위 | *업무 범위 / 업무의 범위* |
| C4 | 보수와 지급 | *보수·자문료* + *지급* 이 한 문장에 |
| C5 | 비밀유지 | *비밀* |
| C6 | 면책 (자문은 의견, 최종 판단 책임은 의뢰인) | *최종 의사결정·최종 판단* + *책임* 이 한 문장에 |
| C7 | 계약 해지 | *해지* |
| C8 | 관할 | *관할* |
| C9 | 손해배상 한도 (받은 보수 총액 한도) | *한도* + *보수* + *배상·책임* 이 한 문장에 |

## C. 빈칸·미완성 (✕ 오류)
`○○`, `OO`, `XXX`, `__`, `[ … ]`, `{{ … }}` 처럼 채우지 않은 자리를 셉니다.
조 제목의 대괄호(`제1조 [목적]`)와 참조 표시(`[별첨]`, `[별표]`, `[붙임]`)는 빈칸으로 세지 않습니다.

## D. 종합 판정 (신호등)
| 판정 | 조건 | 뜻 |
|---|---|---|
| 🔴 서명 보류 | ✕ 오류(필수 조항 누락 또는 빈칸)가 하나라도 있음 | 고치기 전에는 서명하지 않음 |
| 🟡 검토 후 진행 | ⚠ 경고(위험 표현)만 있음 | 걸린 문장을 사람이 확인하고 진행 |
| 🟢 진행 가능 | 아무것도 걸리지 않음 | 그래도 서명 전 최종 확인은 사람이 함 |

## E. 권장 표준 문구
걸린 코드마다 `rules/standard_clauses.md` 의 '권장' 문구를 그대로 보여 줍니다. AI가 새로 짓지 않으며, 문구는 대표가 검토합니다.
