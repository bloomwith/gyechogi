# 계초기 — 계약서 초안 점검기 (Contract Draft Checker)

다른 AI가 써 준 「재무자문 및 자금조달 컨설팅 계약서」 초안을 붙여 넣으면, 위험 표현·빠진 조항·빈칸을 찾아 🔴🟡🟢 신호등으로 판정하고, 고칠 곳마다 검토된 표준 문구를 보여 주는 MVP입니다.
국민대 MBA「AI에이전트실무」(2026 가을학기) 중간 프로젝트입니다.

## 문제
자문사는 새 업체와 계약할 때 AI에게 계약서 초안을 맡기곤 합니다. 그런데 AI 초안에는
- "대출 실행 시 2% 성공보수", "금융기관 알선", "대출 승인 보장"처럼 대부업법·자본시장법 검토가 필요한 표현이 들어가고,
- 자문사를 보호하는 조항(중개하지 않는다, 보수는 성사와 관계없이 지급, 면책)이 빠지며,
- ○○원, [관할 법원] 같은 빈칸이 남기도 합니다. 사람이 매번 처음부터 다시 읽어야 해서 놓치기 쉽습니다.

## 사용자
금융·재무·세무 컨설팅을 하는 1인~소규모 자문사의 대표·실무자 (첫 대상: 재무자문·자금조달 계약)

## 기능
1. 초안 붙여넣기 (시험 초안 불러오기 포함)
2. 3단계 점검: 위험 표현 R1~R3 (⚠ 경고 + 해당 문장), 필수 조항 C1~C8 누락, 빈칸 (✕ 오류)
3. 판정과 고칠 문구: 🔴 서명 보류 / 🟡 검토 후 진행 / 🟢 진행 가능 + 걸린 항목별 권장 표준 문구

규칙 전체는 `rules/review_rules.md`, 권장 문구는 `rules/standard_clauses.md` 를 봅니다.

## 실행 방법
(구현 후 작성)

명령줄 점검:
```
python3 validate_drafts.py                # 시험 초안 8건 점검 + 정답 비교
python3 validate_drafts.py 내초안.md       # 초안 파일 하나 점검
```

## 한계
- 본 도구는 법률 자문이 아니며, 점검 결과는 참고용입니다. 서명 전 금융 법률 전문가의 확인이 필요합니다.
- 점검은 키워드 기반이라 표현을 바꾸면 놓칠 수 있습니다.
- 권장 문구는 검토된 표준 문구만 보여 주며, 반영 여부는 사람이 판단합니다.
- 시험 초안은 모두 합성 데이터입니다.
