## 파일·화면 검증 범위
- TXT/MD, UTF-8 BOM, UTF-16, 확장자 대문자.
- DOCX ZIP stored/deflated, 한글·XML 특수문자·문단·표·탭·줄바꿈.
- DOCX 자동 목록(직접 설정·문단 스타일 설정)의 부정 목록 보존: R2 오탐·C1 누락 오탐 없음.
- PDF/구형 DOC 거절, 손상 ZIP/XML·본문 누락·암호화·빈 문서·잘못된 인코딩·10 MB 초과 거절. 오류 시 기존 입력 보존.
- 압축 해제 후 본문 크기 제한.
- 비동기 읽기 도중 다른 초안 선택 시 늦게 도착한 파일 내용 무시.
- 처음 3문장 표시, `외 N곳` 펼치기/접기.
- 악성 HTML 문자열은 텍스트로 표시, 파일 교체 시 기존 결과 초기화, 빈 입력 안내.
- 390px 모바일 화면 가로 넘침 없음.
- 모든 브라우저 시험에서 페이지 오류 및 HTTP/HTTPS 요청 0건.

## 사용상 한계
- 본문·표 텍스트 중심이며 이미지 OCR·머리말·각주 등은 대상이 아니다. DOCX의 복잡한 서식은 그대로 재현하지 않는다.
- 자동 목록은 점검용 숫자(1. 2. …)로 정규화한다. 원문의 시작 번호·로마자·글머리표·다단계 표시 서식을 복원하는 기능은 아니다. 이 차이를 파일 입력 안내에 명시했다.
- TXT/MD는 UTF-8·UTF-16을 지원한다. 다른 인코딩은 UTF-8로 다시 저장해야 한다.
- 앱에 외부 라이브러리는 없다. 브라우저 테스트 실행에는 개발 도구인 Python playwright와 설치된 Google Chrome이 필요하다.
- 키워드 기반 참고용 점검이다. 최종 계약 판단은 사람·전문가가 한다.

## 독립 검토 후 보완
읽기 전용 리뷰에서 DOCX 자동 번호 소실에 따른 부정 목록 오탐이 지적되었다. 직접 번호·스타일 번호 두 경우 모두 실패를 재현한 다음 목록 구조를 보존하도록 수정했다. 수정 후 전체 Node 18건·Chrome 10건이 통과했다. 커밋·푸시는 하지 않았다.
