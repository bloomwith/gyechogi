# 계초기 규칙 v2 변경안 (AI 3곳 비교 실험 결과 반영)

이 폴더의 파일을 gyechogi 저장소의 같은 위치에 덮어쓰면 v2 규칙이 됩니다.
`python3 validate_drafts.py` 를 돌리면 시험 초안 8건 + 실제 AI 초안 3건이 모두 정답과 일치해야 합니다.

## 왜 바꾸나 (실험에서 발견한 것)
| 발견 | 어디서 | 바꾼 것 |
|---|---|---|
| 놓침: "자금조달에 성공한 경우", "자금조달을 완료한 경우", "조달금액의 ○%" 성공보수를 R1으로 못 잡음 | Gemini, Claude | R1 키워드를 어순·조사 차이까지 넓히고 대출금·투자금·조달금액 추가 |
| 오탐: "중개 또는 대리에 대한 대가가 아님을 확인한다"를 R2로 잡음 | Claude | 부정 표현에 '아님' 추가 |
| 오탐: 의뢰인의 "자료가 정확함을 보장"을 R3로 잡음 | Claude | R3는 대출·투자·조달·승인·성사·유치와 같은 문장일 때만 |
| 오탐: 조 제목 `제1조 [목적]` 9곳, `[별첨]` 2곳을 빈칸으로 셈 | Gemini, Claude | 조 제목 대괄호와 [별첨]·[별표]·[붙임]은 빈칸에서 제외 |
| 오탐: "착수금과 월 자문료는 … 자금조달 성사 여부와 별도로 지급한다"를 R1으로 잡음 | Codex | 부정 표현에 '여부와 별도' 추가 |

## 바뀐 파일
- `validate_drafts.py` — 위 규칙 반영, 실제 AI 초안 회귀 시험(EXPECTED_AI) 추가
- `rules/review_rules.md` — 규칙 표, 정답표, 변경 이력
- `rules/standard_clauses.md` — C6 문구 수정, C9 문구 추가
- `data/drafts/*.md` — 제9조에 손해배상 한도 문장 추가 (draft_08 은 제9조가 없으므로 C6·C9 둘 다 없음이 정답)
- `data/ai_compare/claude.md`, `gemini.md`, `codex.md` — 실제 AI 초안 (회귀 시험용)

## 화면(index.html)에 함께 반영할 것
1. 위 규칙·문구·시험 초안을 index.html 안의 데이터와 로직에 똑같이 반영 (필수 조항 8종 → 9종)
2. 파일 올리기: .txt · .md · .docx 파일을 선택하면 본문 글자를 꺼내 입력 칸에 채움 (외부 라이브러리 없이, 브라우저 안에서만 처리, 서버로 보내지 않음). PDF는 이번에 하지 않음
3. "권장 문구 · 원문 그대로" 표시를 "검토된 표준 문구"로 바꿈 (초안 문장을 그대로 써도 된다는 뜻으로 오해되지 않게)
4. 시험 초안 선택 목록에 실제 AI 초안 3건(Claude, Gemini, Codex) 추가
5. R4처럼 걸린 문장이 많으면 처음 3문장만 보여 주고 "외 N곳"을 눌러 펼치게 함
